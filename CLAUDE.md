## Guardrails

- Countries are reference data only — do **not** add HDI, GDP, government type, or similar socioeconomic fields.
- Join intblocks on `includes[].id`, not `includes[].name`.
- `borders` uses ISO alpha-3 codes; join on `iso3code`.
- Never hand-edit `data/datasets/` (generated by build).

## Validation

```bash
python scripts/validate_countries.py --json
python scripts/validate_intblocks.py --json
```
